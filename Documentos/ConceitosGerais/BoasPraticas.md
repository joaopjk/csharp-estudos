# Dry
Don`t repeat yourself: evite duplicações de código. Centralize toda a Lógica comum em métodos, classes ou pacotes.
# Kiss:
Keep it simple, stupid: prefira soluções simples e diretas. Evite complexidade desnecessária
# Yagni
You aren`t Gonna Need It: não implemente funcionalidades que não são necessárias no momento. Foque no que é realmente utilizado.
# Baixo Acoplamento
Refere-se ao grau de dependência entre módulos, classes ou componentes de um sistema. Significa que as partes do sistema são pouco dependentes uma das outras, facilitando a manutenção, testes, evolução e reutilização do código. Mudanças em módulos tem pouco impacto nas demais.
# Alta Coesão
Refere-se ao grau em que os elementos internos de um módulo ou classe estão relacionadas e trabalham juntos para cumprir uma única responsabilidade. Significa que uma classe ou módulo faz bem uma tarefa especifíca, tornando o código mais organizado, compreensível e fácil de manter.

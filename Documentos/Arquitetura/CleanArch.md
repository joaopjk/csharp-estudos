# Clean Arch
É uma abordagem arquitetural que visa criar sistemas flexíveis, desacoplados, testáveis e fáceis de evoluir. Ela organiza o código em camadas concêntricas, separadas claramente por responsabilidades e invertendo as dependências para proteger o domínio
- Camadas concêntricas(formato de aneis), onde cada camada só pode depender das camadas mais internas
- Inversão de dependência
- Separação de responsabilidades
- Testabilidade
- Ports e Adapters
- Dtos e Mapeamentos
- Boundary
- Controller
- Presenter
- Plugabilidade
